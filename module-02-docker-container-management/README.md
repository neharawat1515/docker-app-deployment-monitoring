# Module 2: Docker Image & Container Management

## Objective
Learn Docker image management and container lifecycle operations.

## Topics Covered
- Docker images and containers
- Pulling images from Docker Hub
- Running containers in detached mode
- Port mapping
- Listing and inspecting containers
- Viewing container logs
- Starting, stopping, and removing containers

## Practical Project
Deploy an Nginx web server inside a Docker container.

## Expected Outcome
A working Nginx container accessible through the Ubuntu host,
with container management commands documented.

## Tools Used
- Ubuntu Linux
- Docker Engine
- Nginx
- Maven 
- Git and GitHub
