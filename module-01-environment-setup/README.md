# Module 1: Environment Setup & Pre-Deployment Verification

## Objective
Verify the development environment before deploying a Java application using Docker.

## Environment
- Operating System: Ubuntu 26.04 LTS
- Docker: 29.1.3
- Java: OpenJDK 21.0.12.1
- Maven: 3.10.0-rc-1

## Tasks
1. Verify the operating system.
2. Check Docker installation and container execution.
3. Verify Java and Maven versions.
4. Confirm Git repository status.
5. Record environment details for deployment.

## Expected Outcome
The environment is verified and ready for application build and Docker deployment.

## Verification Evidence
Commands, actual outputs, and troubleshooting notes are documented in `environment-checks.md` and `troubleshooting.md`.
