# Troubleshooting

## Issue: Maven command not found
Check whether Maven is installed using mvn -version.

## Issue: Java compilation failure
Check the Java version and the maven.compiler.release setting.

## Issue: Maven dependency download failure
Check internet connectivity and Maven repository access.

## Issue: JAR file not found
Confirm that mvn clean package completed successfully.

## Issue: Application fails to run
Check the JAR path and Java error output.
