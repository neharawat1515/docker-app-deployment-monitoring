# Module 3: Java Application Development & Maven Build

## Objective
Develop a Java application and package it using Maven.

## Tools
- Ubuntu Linux
- OpenJDK 21
- Apache Maven

## Application
A simple Java application that prints deployment project status messages.

## Build Command
mvn clean package

## Run Command
java -jar target/deployment-monitoring-app-1.0.0.jar

## Expected Outcome
A successfully compiled Java application packaged as an executable JAR.

## Build Artifact
target/deployment-monitoring-app-1.0.0.jar
